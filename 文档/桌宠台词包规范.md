# 桌宠台词包规范（参考）

> 目标：让“可爱、幽默、轻松”的桌宠不依赖 LLM 也能很好玩；同时允许后续接入 LLM 时复用同一套“台词 + 情绪/动作”结构。

## 1. 设计目标

1. 易制作：普通用户能用记事本/表格就做出一份台词包。
2. 易导入：一个 zip 文件即可导入，支持启用/禁用、优先级、版本管理。
3. 易扩展：同一份台词可绑定情绪、动作、音效、特效；未来可扩展到 Live2D 表情/动作。
4. 可控不打扰：支持冷却时间（cooldown）、概率（weight）、工作模式过滤（workMode）。

## 2. 包形式与目录结构

### 2.1 分发形式
- 台词包以 `zip` 分发，导入后解压到用户数据目录的 `packs/quotes/<packId>/`。
- 禁止 zip 内包含可执行文件与脚本文件（如 `.exe/.dll/.bat/.cmd/.ps1/.sh/.js` 等），只允许资源与数据文件。

### 2.2 目录结构（建议）

```
<packId>.zip
├── manifest.json
├── quotes.jsonl
├── locales/
│   ├── zh-CN.json
│   └── en-US.json
└── assets/
    ├── sfx/
    │   ├── pop.wav
    │   └── meow.mp3
    └── stickers/
        ├── sweat.png
        └── heart.png
```

说明：
1. `manifest.json`：台词包元数据与运行策略。
2. `quotes.jsonl`：按行存储台词条目（便于增量编辑与合并）。
3. `locales/*.json`：可选，放多语言字典或短语模板。
4. `assets/`：可选，放音效、贴纸、小图标等。

## 3. manifest.json 规范

### 3.1 字段定义

| 字段 | 类型 | 必填 | 说明 |
|---|---:|---:|---|
| `id` | string | 是 | 台词包唯一 ID（建议 `kebab-case`） |
| `name` | string | 是 | 展示名称 |
| `version` | string | 是 | 版本号（建议 SemVer，如 `1.0.0`） |
| `author` | string | 否 | 作者 |
| `description` | string | 否 | 简短描述 |
| `license` | string | 否 | 许可说明 |
| `language` | string | 否 | 主语言，如 `zh-CN` |
| `priority` | number | 否 | 优先级，数值越大越优先（默认 0） |
| `enabledByDefault` | boolean | 否 | 默认启用（默认 true） |
| `tags` | string[] | 否 | 台词包标签，如 `cute`、`sarcastic` |
| `compat` | object | 否 | 兼容信息（应用版本范围等） |
| `defaults` | object | 否 | 默认策略（cooldown、workMode 等） |

### 3.2 示例

```json
{
  "id": "cute-chatter-zh",
  "name": "软萌碎碎念（中文）",
  "version": "1.0.0",
  "author": "you",
  "description": "适合轻松模式的短句吐槽、彩虹屁和冷笑话。",
  "language": "zh-CN",
  "priority": 10,
  "enabledByDefault": true,
  "tags": ["cute", "humor", "short"],
  "defaults": {
    "cooldownMs": 5000,
    "maxLen": 60,
    "workMode": "mute"
  },
  "compat": {
    "appMinVersion": "0.1.0"
  }
}
```

## 4. quotes.jsonl 规范

### 4.1 JSONL 说明
`quotes.jsonl` 每行一个 JSON 对象，便于用户用增量方式新增、合并与冲突处理。

### 4.2 字段定义

| 字段 | 类型 | 必填 | 说明 |
|---|---:|---:|---|
| `id` | string | 是 | 条目 ID（同一包内唯一） |
| `type` | string | 是 | 条目类型：`idle`、`tap`、`drag`、`feed`、`reply`、`enter`、`exit` 等 |
| `text` | string | 是 | 展示文本（可包含变量） |
| `mood` | string | 否 | 情绪：`happy`、`shy`、`angry`、`sleepy`、`sad`、`surprised` 等 |
| `anim` | string | 否 | 动画/动作 ID（由桌宠引擎解释） |
| `sfx` | string | 否 | 音效路径（相对 `assets/`） |
| `sticker` | string | 否 | 贴纸路径（相对 `assets/`） |
| `weight` | number | 否 | 权重（默认 1，越大越常被选中） |
| `cooldownMs` | number | 否 | 条目冷却时间（默认继承 manifest.defaults） |
| `minIntervalMs` | number | 否 | 最小触发间隔（比 cooldown 更“全局”） |
| `when` | object | 否 | 触发条件（工作模式、时间段、概率等） |
| `vars` | object | 否 | 本条目专用变量（可覆盖全局） |

### 4.3 when（触发条件）建议字段

| 字段 | 类型 | 说明 |
|---|---:|---|
| `prob` | number | 触发概率 `0~1` |
| `workMode` | string | `allow` / `mute` / `only` |
| `timeRange` | string | 时间段，如 `07:00-10:00` |
| `requiresNickname` | boolean | 是否需要用户设置了昵称 |
| `requiresFed` | boolean | 是否需要“刚投喂过” |

### 4.4 变量模板（建议）

1. 使用 `${var}` 占位。
2. 变量来源优先级：`条目.vars` > `全局上下文` > `locales 字典`。
3. 内置变量建议：

| 变量 | 示例 | 说明 |
|---|---|---|
| `${nickname}` | 小王 | 用户昵称（可为空） |
| `${petName}` | 小团子 | 桌宠名 |
| `${timeOfDay}` | 早上/下午/晚上 | 根据时间段生成 |
| `${randEmoji}` | (｡･ω･｡) | 从表情池抽取 |

### 4.5 条目示例

```json
{"id":"idle-001","type":"idle","text":"我只是路过…顺便可爱一下。${randEmoji}","mood":"happy","anim":"blink","weight":3,"when":{"prob":0.3,"workMode":"mute"}}
{"id":"tap-head-001","type":"tap","text":"哼！你再戳我头试试！(其实有点爽)","mood":"shy","anim":"shake","sfx":"sfx/pop.wav","cooldownMs":8000}
{"id":"feed-001","type":"feed","text":"投喂成功！我宣布：你是全世界最会养宠的人。","mood":"happy","anim":"eat","sticker":"stickers/heart.png","when":{"prob":1}}
```

## 5. 触发类型与语义建议

| type | 触发时机 | 示例 |
|---|---|---|
| `enter` | 应用启动后首次出现 | “我来啦！” |
| `idle` | 空闲碎碎念 | “我在发呆…” |
| `tap` | 用户点击/戳一下 | “别戳啦” |
| `pet` | 摸摸（长按/滑动） | “好舒服…” |
| `drag` | 拖拽移动时 | “我被拎起来了！” |
| `lock` | 锁定位置 | “站岗中。” |
| `unlock` | 解锁位置 | “自由啦！” |
| `feed` | 投喂道具 | “我吃！” |
| `reply` | 用户输入一句话后（离线回复） | “你说得对，但我更可爱。” |

## 6. 运行策略建议

### 6.1 选择算法（建议）
1. 按 `type` 过滤候选集。
2. 过滤 `when`（workMode、timeRange、prob）。
3. 过滤冷却（条目 cooldown + 全局最小间隔）。
4. 按 `weight` 加权随机抽取。

### 6.2 限制策略（建议）
- 每次展示文本长度限制 `maxLen`（避免占屏）。
- 同一条目连续触发限制（最近 N 条去重）。
- 工作模式 `workMode=on` 时只允许 `tap/pet` 等“用户主动触发”的内容，不做 `idle`。

## 7. 本地化（可选）

### 7.1 locales 结构建议

```json
{
  "emoji.pool": ["(｡･ω･｡)", "(￣▽￣)", "(•̀ω•́)✧", "(*≧▽≦)"],
  "time.morning": "早上",
  "time.afternoon": "下午",
  "time.evening": "晚上"
}
```

## 8. 安全与导入校验（强制建议）

| 校验项 | 规则 |
|---|---|
| 文件类型白名单 | 仅允许 `json/jsonl/png/jpg/webp/gif/svg/wav/mp3/ogg` 等资源与数据 |
| 文件大小限制 | 单包总大小建议 < 200MB；单文件建议 < 50MB |
| 路径安全 | 禁止 `../`、绝对路径、符号链接逃逸 |
| manifest 校验 | `id/name/version` 必填；version 语义化；id 合法字符 |
| quotes 校验 | 每行可解析 JSON；必填字段齐全；text 不能为空 |

## 9. 你可以直接用的制作流程

1. 复制模板目录，修改 `manifest.json`。
2. 打开 `quotes.jsonl`，每行写一条短句（先写 50 条）。
3. 放入可选音效/贴纸（没有也可以）。
4. 压缩为 zip 导入测试。
5. 根据“重复度/打扰度”调整 `weight/cooldown/workMode`。
