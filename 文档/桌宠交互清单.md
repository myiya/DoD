# 桌宠交互清单（可爱/幽默/轻松向）

> 目标：让桌宠“交互简单但很有生命力”。所有互动都坚持短句、弱打扰、低学习成本。

## 1. 交互设计总原则

1. 默认只做“用户主动触发”的互动：点一下、摸摸、拖拽、投喂。
2. 主动碎碎念可选：默认频率低，可一键静音/工作模式。
3. 反馈必须“短”：建议 1-2 句，避免长篇建议和办公话术。
4. 互动要“可重复但不腻”：同类动作提供 3-8 条台词轮换，并有冷却。

## 2. 推荐的情绪状态

| mood | 含义 | 常见表现 |
|---|---|---|
| `happy` | 开心 | 眨眼、跳一下、撒花 |
| `shy` | 害羞 | 脸红、躲一下、小声嘀咕 |
| `angry` | 假装生气 | 黑脸、鼓腮帮、转身 |
| `sleepy` | 困 | 打哈欠、眼皮下垂、趴下 |
| `sad` | 假装委屈 | 眼泪、缩成一团 |
| `surprised` | 吓一跳 | 抖一下、弹起 |
| `neutral` | 普通 | 呼吸、眨眼 |

## 3. 交互清单（建议实现 30 个）

字段说明：
- `触发`：用户做什么会发生
- `反馈`：动画/表情/台词
- `冷却`：同类事件最短间隔

## 4. 低成本实现建议（避免做复杂办公能力）

1. 不做：日程、待办、文件读写、OCR、读屏、搜索、自动化工具调用等“专业能力”作为默认卖点。
2. 只做：好玩反馈、台词轮换、少量可选聊天、可选 TTS、可选小玩法。
3. 主动互动只基于“时间 + 用户是否最近互动过”，不做屏幕监控版本。

## 5. 台词风格指南（写作规则）

1. 一条台词建议 10-40 字，最多不超过 60 字。
2. 多用口语、吐槽、反差萌、冷幽默。
3. 禁止输出“专业建议”“任务分解”“工作流”等办公化话术。
4. 避免窥探感：不要说“我看到你在做什么”“我看了你的屏幕”。
5. 允许少量常见网络梗，但要避免过时与攻击性内容。
