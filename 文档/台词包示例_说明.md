# 台词包示例（使用说明）

你现在有两份示例文件：
- `台词包示例_manifest.json`
- `台词包示例_quotes.jsonl`
以及一份扩展文件：
- `台词包示例_quotes_扩展_部位点击.jsonl`

## 如何使用

1. 把 `台词包示例_manifest.json` 和台词文件放到同一个文件夹里（例如 `cute-chatter-zh/`）。
2. （可选）在同级创建 `assets/` 文件夹，放音效/贴纸资源（本示例未附带）。
3. 压缩成 zip：
   - zip 根目录直接包含 `manifest.json` 和 `quotes.jsonl`（不要多套一层目录也行，但要保持相对路径一致）。
4. 如果你想把扩展台词一起用：
   - 最简单做法：把 `台词包示例_quotes.jsonl` 和 `台词包示例_quotes_扩展_部位点击.jsonl` 直接拼接合并成一个 `quotes.jsonl`（按行拼即可）。
   - 或者在引擎里支持“多文件加载”，导入后按优先级合并。
5. 在你的桌宠应用里做“导入台词包”功能时：
   - 解压后读取 `manifest.json`
   - 逐行解析 `quotes.jsonl`（JSONL）

## 这份示例的内容风格

1. 全部是短句、口语、轻吐槽，不走办公场景。
2. 主要覆盖：启动、空闲碎碎念、点击、摸摸、拖拽、缩放、锁定、投喂、轻对话、退出。
3. 扩展文件新增“部位点击/部位摸摸”示例：`when.bodyPart = head/face/belly/tail`（你的引擎可以识别或忽略这个字段）。
3. 使用了变量占位：`${randEmoji}`、`${nickname}`、`${timeOfDay}`，你可以在引擎里自己实现注入逻辑。
